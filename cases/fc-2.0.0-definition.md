# 「量子纠缠」是什么

## 一句话定义
量子纠缠是两个或多个量子系统之间不存在独立个体状态、只能用整体状态来描述的关系。

## 规范定义（权威原文）
国家标准与 ISO/IEC 文献都把「不可分离性」写进定义：复合系统的状态不能写成各子系统状态的直积。

## 边界
纠缠不传递信息，因此不能用于超光速通信。

## 构成 / 运作方式
纠缠通过相互作用产生；对其中一个子系统测量，结果与另一个子系统呈现关联。

## 常见误解
误解一：纠缠等于心灵感应，可以瞬间传话。
误解二：纠缠能被「复制」给第三方。
