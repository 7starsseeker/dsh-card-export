# 某品类竞争格局地图

## 核心发现
该品类前三家合计占据约八成份额，新进入者普遍靠差异化定价挤进细分价位。

## 确定性分层
- 高：份额排名——三家机构的榜单方向一致
- 中：增速——统计窗口不同，口径差 2 个百分点
- 低：明年预测——只有单一机构给出区间

## 分歧在哪
增速的分歧来自统计窗口：自然年与滚动四季度的差别。

## 机制解释
渠道返利与上新节奏共同决定份额波动；返利高时渠道主动压货，榜单份额随之抬高。

## 建议（须标明是建议）
建议先做价格带测试，再决定是否进入该品类。

## 缺口（不知道什么 + 为什么重要 + 拿到什么能补）
缺线下门店出货数据；没有它无法判断增长来自真实需求还是渠道压货；拿到区域抽样后可校准。
